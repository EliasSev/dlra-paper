Master's thesis · summary

Efficient low-rank methods for PDE-based inverse problems

Matrix-free rSVD and DLRA-CG for sparse source identification

Elias J. Severinsen
Supervisors: Ole L. Elvetun, Jonas Kusch

The problem

Find an interior source from boundary measurements

The forward operator \(\mathcal K = \mathcal T\circ\mathcal S\) maps a source \(f\) to the boundary values \(u|_{\partial\Omega}\).

\[\min_f\ \|u-y\|^2_{L^2(\partial\Omega)} + \lambda^2\|Wf\|^2_{L^2(\Omega)}\]
\[-\nabla\cdot\sigma\nabla u + cu = f,\quad \partial_n u = 0\]
Applications: inverse imaging, crack detection, EEG brain mapping.

Why it is hard

Ill-posed: plain Tikhonov pulls sources to the boundary

True source (left) and standard Tikhonov, \(W = I\) (right)

\(\mathcal K\) has rapidly decaying singular values and a large null space, so reconstructions are unstable and non-unique.

Elvetun–Nielsen weights correct the location bias using the SVD \(K = U\Sigma V^\top\):

\[w_i = \frac{\|VV^\top e_i\|_M}{\|\phi_i\|_M}\]

The gap

The weights fix the location, but two problems remain

1. Cost

The weights need \(K\) formed explicitly and its full SVD. Infeasible for large meshes.

2. Smoothing

Weighted Tikhonov is still smooth: true sources are sparse, but distinct sources blur into one connected region.

Problem II, weighted Tikhonov: exact \(K\) (left), rSVD with \(k=10\) and \(k=50\).

Contributions

Two methods, one for each problem

Cost

Matrix-free rSVD

A rank-\(k\) SVD of \(K\) from \(k+p\) forward and \(k+p\) adjoint PDE solves. \(K\) is never formed, so weighted Tikhonov scales.

Smoothing

DLRA-CG

Dynamical low-rank approximation with conjugate-gradient directions: recovers sparse rank-\(r\) sources, much faster than DLRA.

The ranks are independent: \(k\) approximates \(K\), \(r\) is the rank of the source viewed as an \(n\times n\) matrix.

Contribution 1

Matrix-free randomized SVD

Method

Sample the range of \(K\) with PDE solves

  1. Draw \(l = k+p\) random vectors \(\Psi\). Compute \(Y = K\Psi\) (forward solves) and \(Q = \operatorname{orth}(Y)\).
  2. Form \(B = Q^\top K\) row by row with the adjoint: \(b_i = \big(K^*(M_\partial^{-1}q_i)\big)^\top M\).
  3. SVD \(B = \tilde U\Sigma V^\top\), set \(U = Q\tilde U\): \(K \approx U\Sigma V^\top\).

One sparse Cholesky of the PDE matrix is reused for every solve.

Cost

Explicit \(K\): \(N_b\) solves, then a dense SVD.

rSVD: \(2l\) solves, \(\mathcal O(lN_bN)\), with \(l\) a small constant.

Also a variant applying the rSVD to K* (Algorithm 3.2): mixed results, see limitations.

Result: speed

Previously infeasible problems become cheap

13–25×

faster than \(t_K + t_{\text{SVD}}\) at \(N = 100{,}000\) (\(k = 50\) and \(k = 10\)).

The rSVD grows roughly linearly in \(N\); the gap widens with mesh size.

Contribution 2

DLRA-CG

The idea

Sparse sources are low-rank matrices

Reshape \(x\) into an \(n\times n\) matrix \(X\). One square source is rank 1, problem II is rank 3. Search only over \(X = U\Sigma V^\top\) with \(r \ll n\).

Method

DLRA step with conjugate-gradient directions

DLRA (Schotthöfer et al.) updates \(U\), \(V\), \(\Sigma\) along a direction \(D\), then truncates to rank \(r\). With steepest descent or Adam it needs \(\sim 10^4\) iterations.

\(\Phi\) is quadratic with SPD Hessian \(H\), so take \(D\) from CG:

\[\alpha = \frac{\|G\|^2}{\langle D, HD\rangle},\qquad D \leftarrow -G + \beta D\]

Restarts every \(N_r\) steps recompute the true gradient and stop drift. DLRA-PCG adds a preconditioner.

Conclusion

Limitations

rSVD: narrow tests

One elliptic PDE, 2D geometries, square sources. Slow spectral decay needs larger \(k\). The \(K^*\) variant gave mixed results.

Rank choice

DLRA-CG is sensitive to \(r\): too small is wrong, slightly too large looks full-rank.

Semi-convergence

Without restarts it is unclear when to stop; with restarts \(N_r\) must be tuned.

Preconditioning

Iterates drift to non-optimal solutions, worse for preconditioners close to \(H\).

Conclusion

Future work

rSVD

  • Other PDEs, 3D domains, other sources and geometries
  • Power iteration for slow spectral decay
  • Adaptive rank from a tolerance

DLRA-CG

  • Rank-adaptive variant (Schotthöfer et al.)
  • Stopping rules: discrepancy principle, L-curve
  • Convergence theory, incl. preconditioning

Takeaway

Efficient low-rank methods make large-scale sparse source identification possible

  • Matrix-free rSVD: weighted Tikhonov without forming \(K\)
  • DLRA-CG: sparse, well-separated sources, ≈210× faster than DLRA
